# Projetos de IA, sistemas e automação

Projetos desenvolvidos por Bruno Pireth para operações de saúde, educação, vendas e conteúdo. Cada estudo explica o problema, a entrega e uma decisão técnica.

Esta é a documentação pública dos projetos. Os repositórios de implementação permanecem privados.

| Projeto | O que entrega |

| [Agenda e prontuário integrados ao atendimento](agenda-prontuario.md) | Sistema sob medida com agenda, permissões por função e integração com agentes de IA. |
| [Sistema interno para atendimento, vendas e gestão](sistema-operacional-interno.md) | Aplicações conectadas por login, permissões e navegação compartilhados. |
| [Conteúdo e newsletters com IA e revisão humana](maquina-de-conteudo.md) | Da pauta à publicação, com revisão de voz, aprovação e integração aos canais. |
| [Busca por assunto dentro de vídeos](busca-semantica-videos.md) | Pesquisa em linguagem natural que encontra o vídeo e o trecho relevante. |
| [Migração de site para leitura por Google e IAs](migracao-site-geo.md) | Conteúdo disponível no HTML, preservação de rotas e migração planejada. |
